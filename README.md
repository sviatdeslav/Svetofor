# Svetofor
Светофор в среде Proteus на языке C++, собранный на микроконтроллере AVR Atmega329.

Для запуска понадобится скомпилировать код из main и загрузить в микроконтроллер.

![image](https://github.com/user-attachments/assets/6daf1b31-3e41-471a-b9c9-0b960ff2720f)


Схема моделирует светофоры на перекрёстке с пешеходными переходами. Датчик справа заменяет датчик освещённости - при значении 50 или выше запускается "ночной режим", при котором гоорит светодиод и пешеходный переход запускается только по нажатию кнопки PE0. Нажатие кнопки PE2 отключает светоформ полностью. Кнопка PE3 включает режим "жёлтого мигания" светофоров.
